PCB designed in KiCad,

Code for ESP32 in Arduino

-read data from motor controller, battery BMS
-collect GPS data
-log all data to sdcard
-send data to pitcrew
-show important metrics and any warnings to driver
-enable recording cool videos with data synced to video time
